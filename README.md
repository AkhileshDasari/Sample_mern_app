## 🛠️ What's Inside?

Like a developer's kitchen drawer, you'll find a little bit of everything:

| Folder | What it actually is | Secret Truth |
| :--- | :--- | :--- |
| **`html_basics/`** | Standard HTML skeletons | Mostly `<div>` tags nested into infinity. |
| **`css_basics/`** | Colors, fonts, and layouts | 90% spent trying to center a `div`. |
| **`javasctipt-exp/`** | Core JS logic & scripts | `console.log("here")` on line 42. |
| **`jquery_exp/`** | Good ol' jQuery interactions | Because DOM manipulation shouldn't take 10 lines of vanilla JS. |
| **`bootstrapexp/`** | Pre-built responsive elements | Making things look good without actual CSS knowledge. |
